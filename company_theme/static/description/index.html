Company Backend Theme Color

Choose a primary accent color for each company in Odoo 18.

Company Backend Theme Color applies the selected company color to standard primary styling in the Odoo backend.

Features

  • Store a separate primary accent color on each company.
  • Apply the color to standard Odoo and Bootstrap primary styling, including primary buttons, links, navigation, tabs, focus rings, and selected states.
  • Derive hover and active shades from the selected color.
  • Keep semantic success, warning, and danger colors unchanged.
  • Standard components that use Odoo or Bootstrap primary styling inherit the configured color without per-module changes.

Configuration

  1. Open the company form.
  2. Go to the Themes tab.
  3. Set Company Theme Color and save.
  4. Reload the backend to apply the color for the active company.

Compatibility and behavior

  • Compatible with Odoo 18. The color is read from the active company when the backend loads.
  • Components that define their own hardcoded colors, including third-party modules, are not forcibly recolored.
