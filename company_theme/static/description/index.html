Company Theme for Odoo 18

A company-specific primary accent for the Odoo backend.

Choose a primary accent color for each company and let standard Odoo backend components follow it. The included Enterprise companion addon also lets each company choose an Apps/Home screen background image.

Key features

  • Configure a separate backend primary color for each company.
  • Apply the configured accent to standard primary buttons, links, hover and active states, focus indication, selections, tabs, dropdowns, and other supported Odoo/Bootstrap primary styling.
  • Derive interactive color shades from the selected company color.
  • Keep semantic success, warning, and danger colors distinct.
  • Standard Odoo and custom modules using native Odoo/Bootstrap primary styles inherit the configured color without per-module changes.
  • On Enterprise, optionally set a company-specific background image for the Apps/Home screen.

Third-party components with explicitly hardcoded colors are not forcibly recolored.

Community Edition

Odoo 18 Community

  • Company-specific backend primary color.
  • Standard Odoo primary accents follow the selected color.

Enterprise Edition

Odoo 18 Enterprise

  • Company-specific backend primary color.
  • Optional company-specific Apps/Home background image.

The background feature is included through the technical company_theme_enterprise companion addon; it is part of this product, not a separate listing.

Multi-company

Each company can have its own primary color. In Enterprise, each company can also have its own Apps/Home background. The active company settings are applied when the backend loads or reloads.

Configuration

  1. Open the company form and select the Themes tab.
  2. Set Company Theme Color and save.
  3. On Enterprise, optionally upload an Apps Menu Background image and save.
  4. Reload the backend to apply the active company's configuration.

Compatibility

Odoo 18 Community and Enterprise.
